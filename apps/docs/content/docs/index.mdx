---
title: Unknown Planet
description: A storage-neutral data layer for graph, vector, memory, and document retrieval.
---

Unknown Planet gives an application one TypeScript client for scoped knowledge storage and retrieval. It routes each capability to a provider, so a deployment can combine relational, document, vector, and blob systems behind one API.

## Packages

| Package | Purpose |
| --- | --- |
| `@unknown-planet/core` | Storage-neutral domain types and provider contracts. |
| `@unknown-planet/sdk` | `Planet` client, routing, ingestion, and retrieval. |
| `@unknown-planet/postgres` | PostgreSQL stores, including pgvector support and migrations. |
| `@unknown-planet/mongodb` | MongoDB stores and Atlas Vector Search adapter. |

Unknown Planet orchestrates providers; it is not a database engine or ORM. Applications own their database infrastructure, credentials, and deployment policy.
