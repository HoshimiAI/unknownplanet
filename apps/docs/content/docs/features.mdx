## Workflow examples

- **Search an existing corpus:** configure embeddings, a vector store, graph and chunk stores, then call `planet.query`.
- **Ingest files into searchable knowledge:** call `document.ingest`; add a parser for binary formats and an extractor if graph facts are needed.
- **Remember a conversation:** use `memory.add` for embedding plus graph integration, or `memory.persist` when another system owns embedding and graph work.
- **Keep provenance:** add evidence for sourced edges and retrieve it with graph search or `includeEvidence`.
- **Run across customers:** derive a scope from verified authentication context and use `withScope` for each request.

See [Providers](/docs/providers) for backend capability matrices and setup requirements.
